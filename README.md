# My Travel Diary

This website tells the story of a road trip across the USA in July 2023, exploring iconic cities such as Los Angeles, San Francisco, and San Diego, as well as breathtaking natural wonders like Bryce Canyon, Antelope Canyon, Monument Valley, and Sequoia National Park. It captures the unforgettable landscapes, places, and experiences of an incredible American adventure.

## Live site

https://veronicaruta.github.io/travel-diary/

## About the project

This website showcases my July 2023 road trip across the USA and is designed for anyone interested in travel, nature, and discovering new places. It was created as a university project for the Web Communication course, within the COM degree program, during the 2026/2027 academic year.

## Pages

- index.html: home page with hero section and three canyon cards
- grand-canyon.html: my visit to the Grand Canyon
- antelope-canyon.html: my visit to Antelope Canyon
- bryce-canyon.html: my visit to Bryce Canyon

## Technologies

- HTML with semantic tags (header, nav, main, section, article, footer)
- CSS in an external stylesheet (css/mystyle.css)
- JavaScript
- Flexbox for the navigation menu and the responsive photo cards
- Google Fonts (Playfair Display, Lato)
- Git and GitHub for version control, GitHub Pages for publishing
- Visual Studio Code as editor
